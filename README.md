# Store
Order management on store inventory using ExpressJS.

## 🚀 Features

- **ExpressJS 5.1.0** - Latest stable version

## 📋 Prerequisites

- **NodeJS 24.11** or higher
- **NPM 11.6** or higher

## 🛠️ Quick Start

### 1. Clone the Repository

```bash
git clone <repository-url>
cd storeinnodejs
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start server

```bash
node server.js
```

The application will start on `http://localhost:3000`

## 📚 Available Endpoints

Currently, the application provides:

- **Root**: `GET http://localhost:3000` 
- **Customers**: `http://localhost:3000/api/Customers` 
- **Products**: `http://localhost:3000/api/Products` 
- **Orders**: `http://localhost:3000/api/Orders`
